# ADR-008: Transactional Outbox Pattern for Asynchronous Side Effects

## Status
Accepted (2026-09-21)

## Context
When domain state changes occur—such as creating a feed post (`POST /families/:id/feed`) or publishing tree updates—secondary side effects must be triggered (e.g. Web Push notifications and email magic link delivery). Dispatching network requests directly inside the mutating transaction causes slow HTTP client calls to hold database locks, risking pool exhaustion. Conversely, launching asynchronous goroutines after transaction commit (`go sendNotification()`) risks silent message loss if the container crashes or restarts before the goroutine executes.

## Decision
1. **Outbox Events Table**:
   - Persist side-effect intents in a dedicated `outbox_events` table inside the exact same database transaction that modifies domain entities:
     ```sql
     CREATE TABLE outbox_events (
         id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
         topic TEXT NOT NULL,
         payload JSONB NOT NULL,
         created_at TIMESTAMPTZ NOT NULL DEFAULT NOW(),
         processed_at TIMESTAMPTZ
     );
     CREATE INDEX idx_outbox_unprocessed ON outbox_events(created_at) WHERE processed_at IS NULL;
     ```
2. **Background Outbox Drainer**:
   - An asynchronous background worker polls `outbox_events` for unprocessed records (`processed_at IS NULL`), processes notifications (Web Push VAPID, email delivery), and marks records completed with `processed_at = NOW()`.
   - Topics include `feed.created` and `magic_link.send`.
3. **At-Least-Once Delivery**:
   - Operations are designed to tolerate retries; external push and email dispatches accept idempotency or at-least-once semantics.

## Consequences
- **Positive**: Mutation HTTP requests return quickly without waiting for third-party Web Push or SMTP network latency.
- **Positive**: Guaranteed message durability across application server restarts or sudden crashes.
- **Negative**: Requires a persistent polling background worker in the API binary and periodic cleanup of processed outbox entries.
