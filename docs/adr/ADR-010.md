# ADR-010: Hybrid Canvas-DOM Tree Rendering & Strict Structural Text Contract (INV-05)

## Status
Accepted (2026-09-21)

## Context
Rendering complex family trees spanning hundreds of members across 5+ generations presents distinct frontend performance and accessibility challenges. Pure SVG implementations degrade mobile performance (>5,000 SVG DOM elements lead to frame drops and memory spikes during pinch-to-zoom). Conversely, pure HTML Canvas destroys accessibility, makes text selection impossible, and complicates responsive Vietnamese diacritics. In addition, invariant INV-05 mandates that kinship calculation results render strictly as bare text in the DOM, with decorative quotes injected exclusively via CSS.

## Decision
1. **Hybrid Visualizer Architecture**:
   - **Connector Edges**: Rendered on an HTML5 `<canvas>` layer using smooth cubic Bézier curves.
   - **Node Cards**: Rendered as windowed, culled HTML DOM elements with an active budget capped at `< 300` DOM elements at any zoom level (visible cards plus a $1.5\times$ viewport buffer).
   - At zoom levels $< 0.6\times$, cards automatically collapse to lightweight dot markers.
2. **Transform-Only Gesture Performance**:
   - Pan and zoom gestures are processed through unified Pointer Events (`setPointerCapture`) updating exclusively GPU-accelerated CSS transforms (`translate3d` and `scale`).
   - The tree viewport sets `touch-action: none` to eliminate iOS pull-to-refresh conflicts.
   - Reactive state uses Vue 3 `shallowRef` for graph topology; node selection does not trigger layout recalculations.
3. **Structural Kinship Text Enforcement (INV-05)**:
   - In `KinshipResult.vue`, the kinship term is rendered strictly via a plain text interpolation:
     `<span data-testid="kinship-term" class="kinship-term-quoted">{{ result.term }}</span>`.
   - Quotation marks are injected strictly through CSS pseudo-elements:
     `.kinship-term-quoted::before { content: '\201C'; }`
     `.kinship-term-quoted::after { content: '\201D'; }`.
   - Zero `v-html` is permitted app-wide.
4. **Self-Hosted Offline Fonts**:
   - Self-host "Be Vietnam Pro" and "Fraunces" fonts via `@fontsource` packages, ensuring full offline capability (INV-01) and removing Google Fonts from Content Security Policies.

## Consequences
- **Positive**: 60fps smooth pan and zoom on mobile devices even with trees exceeding 1,000 members.
- **Positive**: Complete compliance with INV-05 verification tests (`textContent === "Ông nội"`).
- **Negative**: Requires maintaining synchronized coordinates between the background `<canvas>` and foreground HTML card overlays.
