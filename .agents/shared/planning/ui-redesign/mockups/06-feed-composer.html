Ghi chú thiết kế — Feed composer

  • Khởi đầu bằng con người: avatar 40px (36px mobile) + textarea không viền bg-transparent border-0 focus:ring-0 resize-none — cảm giác “nói chuyện với gia đình”, viền thẻ bao ngoài thay viền input (idiom composer chuẩn, bớt “form”).
  • Ô URL ảnh = ghost field: viền đứt + nền bg-cream-muted/60 + icon link — tín hiệu “khả dụng nhưng phụ kiện”, khác cấp với nội dung chính. Nút “Thêm ảnh” thu thành “Thêm” ở mobile.
  • Chip ảnh có thumbnail: ô tròn nhỏ màu gen-soft + icon ảnh + tên file rút gọn (full URL ở title) + nút x nhỏ — thay chip URL text dài hiện tại.
  • Footer soạn: helper text (“hiển thị cho cả gia đình · tối đa 4 ảnh”) + bộ đếm ký tự 128/500 + nút Đăng bài kèm icon paper-airplane. Disabled state: nút mờ + không icon bay.
  • Khách chưa đăng nhập: banner ấm terracotta-soft + icon khóa + CTA terracotta (không đổi hành vi, chỉ đổi lớp màu từ slate lạnh sang ấm).
  • Feed PostCard giữ nguyên idiom — chỉ nâng cấp: avatar tác giả là ảnh thật/fallback, placeholder ảnh màu gen-soft trong mockup (bản thật là ảnh URL). Feed composer + member-detail posts tab giờ dùng cùng một ngôn ngữ.
