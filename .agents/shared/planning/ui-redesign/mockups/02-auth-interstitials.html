Bước 2/3 · Đang trao đổi token

Ghi chú thiết kế — Auth interstitial

  • 1 component, 2 route: AuthInterstitial.vue nhận props eyebrow / state / title / message / retry? — thay thế 2 file EmailVerifyView + OAuthCallbackView gần như trùng nhau.
  • Đĩa trạng thái (status disc): 64px, working = bg-terracotta-soft + spinner terracotta; success = bg-emerald-100 text-emerald-600; error = bg-rose-100 text-rose-600 — cùng bộ icon check-circle / exclamation-circle 2px stroke.
  • Mini stepper 3 chấm cho OAuth callback (Chuyển hướng → Trao đổi token → Vào ứng dụng); ẩn ở state success/error, thay bằng nút hành động.
  • Success có nút dự phòng “Vào cây gia phả” — tự chuyển hướng sau ~1.5s nhưng người dùng chậm mạng có thể bấm thay vì chờ.
  • Error luôn 2 lối ra: Thử lại (outline, chỉ hiện khi còn token) + Về trang đăng nhập (text link terracotta).
  • Không bottom-nav / header trên các route này (giữ nguyên hành vi hiện tại) — nền kem + ghost “Phả” đủ brand.
